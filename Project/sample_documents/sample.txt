Fast Substrings Search Using Suffix Arrays and Binary Search

Abstract:
In modern computer science and software engineering, fast pattern matching over large text documents is a critical requirement.
This research paper evaluates the performance of Suffix Array based substring search using binary search.
Machine learning models, natural language processing pipelines, and genetic sequence alignment often require searching for repeated patterns in static text databases.

1. Introduction to Data Structures:
Naive substring search algorithms scan through the text for every pattern query, resulting in O(N * M) worst-case time complexity.
By contrast, a Suffix Array preprocesses the text document of length N into a sorted array of suffix starting positions.
After preprocessing, multiple pattern queries can be executed in O(M log N) time using binary search.
Applications of machine learning and artificial intelligence can leverage Suffix Arrays for rapid indexing.

2. Algorithm Methodology:
The core algorithm consists of two phases:
Phase 1: Suffix Array Construction using Rank-Based Prefix Doubling. Initial ranks are assigned based on character ASCII values.
In each doubling step, suffix indices are sorted by rank pairs (rank[i], rank[i + k]). Ranks are updated until all ranks are unique.
Phase 2: Binary Search Substring Pattern Search. Binary search locates the lower bound and upper bound in the Suffix Array where the suffix prefix matches the search pattern.

3. Results & Evaluation:
Experimental evaluations show that Suffix Arrays provide exponential speedups for repeated queries on large text documents.
Machine learning models can be trained using extracted feature snippets from large texts.
Data structures like Suffix Arrays remain indispensable for high-performance substring searching.
